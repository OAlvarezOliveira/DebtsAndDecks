# Gemini prompt sheet — card illustrations, one card at a time

Each numbered block below is a **complete, self-contained prompt**. Copy one block, paste it into
Gemini, generate, save the PNG under the filename in the heading, move to the next. Nothing has to
be assembled and nothing else has to be pasted with it.

The italic line under each heading is the card's rules text. It is there so you can check the
illustration matches what the card does — **never paste it**, and never ask for it to be drawn. The
game renders name, cost and description live, in the player's language.

Save to: `app/src/main/assets/art/cards/<filename>`. Filenames are load-bearing: the renderer
resolves art by card id.

Companion to [`ART-PROMPTS.md`](ART-PROMPTS.md), which records why each asset is being regenerated.
